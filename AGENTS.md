# AGENTS.md

## Team rules (gunner-platform-brain)
- Start of every session: read gunner-platform-brain `CURRENT-STATE-BRIEFING.md` and, if this work touches another app, its `SEAMS/` file.
- End of every session that changed anything: post ONE comment on the GitHub issue(s) the work came from (and the PR, if any): **<what changed, one line>**, then where it is (DEV/QA/PROD + sha), switches flipped, what's next and who it's waiting on. @-mention the owner if you touched their area (see `SWIM-LANES.md`). No secrets, customer data or keys.
- Working in someone else's app: small reversible fixes → do it and tag them; bigger changes → they review the PR; contracts, data, money, security → ask them first in the issue. Requests to another owner = a tagged GitHub comment.
